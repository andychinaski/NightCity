# Ночной город — управляемый мультфильм

**G2. Единая логика движения для Canvas 2D-версии.**

## Быстрый запуск

1. Распакуй ZIP целиком, сохранив вложенные папки.
2. Открой `index.html` двойным щелчком в Chrome, Edge или другом современном браузере.
3. Нажми большую кнопку **Play**. Внизу — горизонтальный / вертикальный параллакс и скорость дороги.

Никакой `npm install`, сборки, сервера, интернета и Three.js не требуется. Все исходные PNG, кадры анимации и MP3 включены. Дополнительно можно запустить локальный сервер командой `python -m http.server 8000` и открыть http://localhost:8000/.

## Структура

- `index.html` — разметка сцены, Canvas и элементы управления
- `css/style.css` — исходные стили
- `js/assets.js` — манифест путей и загрузка кадров
- `js/motion.js` — состояние движения, время анимации, скорости и коэффициенты слоёв
- `js/scene.js` — отрисовка слоёв, спрайтов и дождя на Canvas 2D
- `js/controls.js` — кнопки, ползунки, музыка
- `js/main.js` — создание приложения и цикл кадров
- `assets/backgrounds/` — небо, дальний и средний город
- `assets/streets/` — улица, парк, супермаркет
- `assets/sprites/` — машина и пешеход
- `assets/icons/` — иконки кнопок
- `assets/audio/` — музыкальная дорожка
- `references/threejs/` — **только справочные JS** из экспериментальной 3D-версии, не подключаются к сцене

## Как работает движение

- `motion.js` накапливает `worldDistance` по скорости дороги. При 100% улица проходит 255 пикселей в секунду, средний город — 65, дальний — 8. `scene.js` рассчитывает позиции слоёв от этой дистанции и циклически прокручивает текстуры.
- Ползунки параллакса задают смещения при отрисовке. Ими можно пользоваться на паузе. Ручное смещение не учитывается в прогрессе маршрута.
- Дождь и кадры пешехода идут по времени анимации. Машина использует отдельное время, которое накапливается пропорционально скорости дороги. На 0% остаётся текущий кадр машины.
- Пешеход появляется на первом переходе от улицы к парку и на том же участке каждого следующего круга. Его собственный шаг — 180 пикселей в секунду относительно улицы. На экране к шагу добавляется прокрутка улицы.
- На паузе `main.js` продолжает отрисовку для ручного параллакса. При возобновлении он начинает отсчёт интервала заново, чтобы сцена не перескакивала вперёд.

В `assets/sprites/car-original-unused.png` сохранён дополнительный исходный PNG автомобиля, который не использовался в старом HTML.

## Что проверено

- При 100% сравнили параметры отрисовки G1 и G2 на 1 801 кадре, включая дождь, пешехода, оба ползунка параллакса и полный круг маршрута.
- Проверили пропорции скорости на 0%, 50%, 100% и 200%, остановку кадра машины, движение дождя и уже появившегося пешехода при 0%, паузу и первый кадр после возобновления.
- Проверили стыковку координат дорожных текстур на нескольких кругах, включая переход от супермаркета к улице.
- Запуск через `file://` и визуальный вид стыков в браузере остались непроверенными. Автоматическая проверка загружала скрипты из `index.html` в Node.js с подстановкой DOM и Canvas.

## Git

`.gitignore` исключает временные и служебные файлы, но **не исключает `assets/`**: изображения и музыку нужно коммитить, иначе репозиторий не будет запускаться у другого человека.
