# Справочные исходники Three.js-прототипа

Эти семь JavaScript-файлов приложены **только как reference для последующей задачи G2** (Hybrid X / вертикальная камера). Они не подключены к `index.html` и не являются полноценным запускаемым 3D-проектом: CSS, HTML, ассеты и зависимости того эксперимента сюда не переносились. Источник работающей сцены — Canvas 2D в корне архива.
